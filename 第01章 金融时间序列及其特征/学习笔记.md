## 1. 资产收益率（Asset Returns）

一切分析的对象都是**收益率**而非**价格**。原因：价格序列非平稳（均值随时间漂移），收益率近似平稳，可用统计方法处理。

### 1.1 单期简单收益（Simple Return）

设 $P_t$ 为 $t$ 期价格，$D_t$ 为分红：

$$
R_t = \frac{P_t + D_t}{P_{t-1}} - 1 = \frac{P_t - P_{t-1} + D_t}{P_{t-1}}
$$

- 即"持有期收益率"，可用于跨资产**加总**（组合收益是成分收益的加权平均）。
- 缺点：**不能跨时间加总**——多期收益不是单期收益之和，而是连乘。

### 1.2 多期简单收益（k 期）

$$
R_t(k) = \frac{P_t + D_t - P_{t-k}}{P_{t-k}} = (1+R_t)(1+R_{t-1})\cdots(1+R_{t-k+1}) - 1
$$

年化时：月收益 ×12、日收益 ×252 只是近似。

### 1.3 对数收益（Log Return / 连续复利收益）

$$
r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = p_t - p_{t-1}, \quad p_t = \ln P_t
$$

- 多期对数收益 = 单期对数收益**求和**：$r_t(k) = r_t + r_{t-1} + \cdots + r_{t-k+1}$ —— 这是统计建模偏爱与对数收益的根本原因。
- 与简单收益的关系：$r_t = \ln(1+R_t)$；当收益很小时 $r_t \approx R_t$（差异在 2% 以内可忽略，大跌时差异显著：$R=-20\% \Rightarrow r\approx -22.3\%$）。
- 注意：对数收益**不能跨资产加总**（组合的对数收益 ≠ 成分对数收益的加权平均），与简单收益正好互补。

| 操作 | 简单收益 | 对数收益 |
|---|---|---|
| 跨时间（多期） | 连乘 | **求和** ✓ |
| 跨资产（组合） | **加权平均** ✓ | 不可加 |

### 1.4 组合收益与超额收益

- 组合简单收益：$R_{p,t} = \sum_{i=1}^{N} w_i R_{i,t}$（权重 $w_i$，需定期再平衡否则漂移）。
- 超额收益（excess return）：$Z_t = R_t - R_{0t}$（相对无风险利率，如 3 个月国库券）。这是 CAPM/均值-方差理论的输入量。

### 1.5 几个实务要点

1. 日收益中隔夜/非交易时段的处理：用收盘对收盘收益，日内高频数据另见第 5 章。
2. 缺失值：周末与节假日无数据，日序列实际是"交易日序列"，建模时不要虚构均匀时间轴。
3. 分红送转：A 股需用**后复权/前复权**价格计算收益，否则除权日会出现虚假暴跌。
4. 自有数据的落地：我们用 thsdk 抓的日 K 已是复权口径，做收益序列时统一取 `close`（复权）的 diff-log。

## 2. 收益率的分布性质（Distributional Properties）

### 2.1 平稳性假设

设 $p_t = \ln P_t$。多数统计模型假设**收益率序列** $\{r_t\}$ 是平稳的：
- 一阶矩、二阶矩不随时间变化；
- 自协方差只依赖时间间隔。

实证上：对数价格通常有单位根（非平稳），对数收益率近似平稳。这是"价格差分/取对数差分"的标准操作依据。

### 2.2 收益率的矩

对样本 $r_1,\dots,r_T$：

| 统计量 | 公式（样本） | 金融含义 |
|---|---|---|
| 均值 | $\hat\mu = \frac{1}{T}\sum r_t$ | 长期平均回报；日频上常近似为 0 |
| 方差 | $\hat\sigma^2 = \frac{1}{T-1}\sum (r_t-\hat\mu)^2$ | 风险；年度化 $\hat\sigma^2 \times 252$（A股交易日数） |
| 偏度 | $\hat S = \frac{m_3}{\hat\sigma^3}$，$m_3=\frac{1}{T}\sum(r_t-\hat\mu)^3$ | 收益分布不对称性；负偏 → 大跌比大涨更极端 |
| 峰度 | $\hat K = \frac{m_4}{\hat\sigma^4}$，$m_4=\frac{1}{T}\sum(r_t-\hat\mu)^4$ | 尾部厚度；正态分布为 3，**超额峰度** $\hat K - 3$ |

- A 股个股日收益：超额峰度普遍在 3～15（厚尾显著），偏度通常为负或接近 0；指数比个股更接近对称。
- 年化公式：$\sigma_{年} = \sigma_{日}\sqrt{252}$（对数收益严格成立，简单收益近似）。

### 2.3 收益率分布形状

- 直方图 vs 同均值同方差正态曲线：实际分布**尖峰（leptokurtic）+ 厚尾**，中间高两侧厚。
- 极端收益出现的频率远高于正态假设 → "8 个标准差的事件"在正态下几百万年一遇，市场中几年一遇。

### 2.4 分布检验：Jarque–Bera 统计量

$$
\mathrm{JB} = \frac{\hat S^2}{6} + \frac{(\hat K - 3)^2}{24} \quad \sim \quad \chi^2_2 \text{（正态原假设下）}
$$

- 大样本检验；JB 越大越拒绝正态。A 股日收益几乎全部强烈拒绝正态。
- 用途：提醒我们基于正态假设的 VaR、期权定价、置信区间都要打折扣（第 6、7 章展开）。

### 2.5 收益率分布的经验模型（书中对比了四类）

1. **正态**：$r_t \sim N(\mu,\sigma^2)$ —— 便于推导，但厚尾刻画失败。
2. **对数正态**：价格 $P_t$ 对数正态、$1+R_t$ 对数正态 —— Black-Scholes 世界的假设，与厚尾实证矛盾。
3. **稳态分布（stable distribution）**：允许无穷方差，尾部幂律衰减 —— 代价是二阶矩不存在，多数经典方法失效。
4. **混合与广义 λ 分布**：用有限混合或分位数变换拟合厚尾 —— 实务中拟合效果好。

> 本课程结论：**不必执着于找一个"正确"的全局分布**，后续各章用条件异方差（第 3 章）+ 极值理论（第 7 章）分而治之。

## 3. 收益率的经验特征（Stylized Facts）★ 全章核心

以 IBM 日对数收益（含分红）为例，本书总结出以下事实，A 股同样成立：

1. **收益自相关很弱**：日收益 ACF 几乎都在置信带内 → 线性可预测性弱（但非零，第 2 章用 ARMA 捕捉残存的小相关性）。
2. **平方/绝对收益自相关强且衰减慢**：$|r_t|$ 的 ACF 显著为正、持续几十上百期 → 波动有聚集性与长记忆 → 这是第 3 章（GARCH）与第 4 章的动机。
3. **收益率与 $|r_t|$ 负相关**（杠杆效应的直观来源，第 3 章的 EGARCH/TGARCH 处理）。
4. **无条件分布尖峰厚尾**，但**条件正态 + 时变方差**可以解释大部分厚尾 → "波动率建模是化解厚尾的钥匙"。
5. 极端负收益比极端正收益更多（偏度为负，尤其指数）。

### 3.1 一图流理解第 1 章 → 后续章节的动机链

```
厚尾(峰度高)  ──→ 条件异方差模型 (第3章 GARCH)
                              └─→ 无条件分布 = 波动率混合 → 接近正态 ✓
|rt| 长记忆   ──→ 长记忆/分形模型 (第4章)
尾部风险      ──→ 极值理论 + VaR (第7章)
多资产联动    ──→ 多元时间序列 (第8章) / 因子模型 (第9章) / 多元波动率 (第10章)
```

## 4. 本书研究的过程（Processes Considered）

书中明确后续考虑的序列类型，作为路线图：

1. **ARMA 过程**：条件均值建模（第 2 章）。
2. **GARCH 过程**：条件方差建模（第 3 章）。
3. **扩散过程**：连续时间（第 6 章，期权）。
4. **状态空间/局部趋势**（第 11 章）、**MCMC 贝叶斯**（第 12 章）。

统一框架：$r_t = \mu_t + \varepsilon_t$，$\varepsilon_t = \sigma_t e_t$ —— 均值方程 + 方差方程，全书大部分章节都在精细化这两个方程的某一半。
